# Inter Font Files

Copy the Inter font files from the main blog's `static/fonts/` directory:

```bash
cp /path/to/web-hacker1db/main/static/fonts/Inter-*.woff* ./
```

Required files:
- Inter-Regular.woff2, Inter-Regular.woff
- Inter-Italic.woff2, Inter-Italic.woff
- Inter-Medium.woff2, Inter-Medium.woff
- Inter-MediumItalic.woff2, Inter-MediumItalic.woff
- Inter-Bold.woff2, Inter-Bold.woff
- Inter-BoldItalic.woff2, Inter-BoldItalic.woff
